# Media clínico: subida por API y acceso renovable

## Modelo mental

| Capa | Caduca | Rol |
|------|--------|-----|
| MongoDB (`object_key`, metadatos) | No | Índice clínico permanente |
| Objeto en MinIO | No | Binario real |
| URL presignada (GET/PUT) | Sí (configurable) | Puente temporal; se **vuelve a emitir** |

Un landmarks de hace 3 meses **sigue en MinIO**. Para verlo el front pide una URL nueva (Bearer JWT), no reutiliza enlaces viejos en caché.

## Subida sin presign (navegador → API → MinIO)

Para evitar Mixed Content y CORS en MinIO (ficheros ≤ ``MAX_PROXY_UPLOAD_BYTES``, default **64 MiB**; nginx: ``docs/14.nginx_api_upload_limits.md``):

| Método | Ruta | Cuerpo |
|--------|------|--------|
| POST | `/api/v1/landmarks/upload` | `multipart/form-data`: campos de sesión + `file` |
| POST | `/api/v1/audio/upload` | idem |

Los flujos presignados (`POST /landmarks`, `POST /audio` + PUT) siguen para nilo-node y vídeo pesado.

## Acceso por fichero (visualizar landmarks, audio, vídeo…)

Cada recurso en MinIO se lee con **JWT**; la API devuelve una URL presignada temporal (no hace falta abrir MinIO al navegador sin auth).

| Método | Ruta | Notas |
|--------|------|--------|
| GET | `/api/v1/landmarks/{id}/download?expires_in=3600` | JSON `PresignedDownload` |
| GET | `/api/v1/landmarks/{id}/file` | Stream por API si presign falla |
| GET | `/api/v1/audio/{id}/download` | Igual |
| GET | `/api/v1/audio/{id}/file` | Igual |
| GET | `/api/v1/sessions/video-segments/{id}/download` | Vídeo |
| GET | `/api/v1/pain-events/{id}/download` | Clip dolor |
| GET | `/api/v1/medical-documents/{id}/download` | PDF, etc. |
| GET | `/api/v1/storage/access?kind=landmarks&resource_id=…&expires_in=3600` | **Genérico** (misma caché) |

`expires_in`: segundos (**mín. 60**, **máx. 7 d**). Por defecto en un fichero: ``MINIO_VIEW_EXPIRY`` (**3600** = 1 h).

El servidor **reutiliza** la misma `download_url` para el mismo objeto y TTL mientras no haya caducado; al día siguiente, una nueva petición genera un token nuevo.

Respuesta `PresignedDownload`: `download_url`, `expires_in`, `expires_at` (UTC).

**Frontend landmarks:** `GET …/download` → `fetch(download_url)` con el JSON; si CORS/Mixed Content, `GET …/file` con Bearer.

## Renovación al abrir una sesión (lote)

```http
GET /api/v1/sessions/{session_id}/media-access?expires_in=86400
Authorization: Bearer …
```

Lista `items[]` con presigns para todo lo subido. Default TTL lote: ``MINIO_DOWNLOAD_EXPIRY`` (24 h).

## Configuración

```yaml
MINIO_DOWNLOAD_EXPIRY: 86400
MINIO_PRESIGN_EXPIRY: 3600   # solo PUT de subida presignada
MAX_PROXY_UPLOAD_BYTES: 33554432
```

HTTPS en presignas: `docs/10.minio_browser_uploads.md`.
