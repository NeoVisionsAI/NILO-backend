# Frontend: notas de texto y audio en sesión

Base URL API (ejemplo producción):

```text
https://nilomed.eu/api/v1
```

Todas las rutas requieren header:

```text
Authorization: Bearer <access_token>
```

---

## 1. Nota de texto (solo MongoDB, sin MinIO)

Texto clínico asociado a una sesión. El cuerpo se guarda cifrado en la base de datos.

### Crear nota

```http
POST /sessions/{session_id}/text-notes
Content-Type: application/json
```

Cuerpo:

```json
{
  "patient_id": "675abc...",
  "node_id": "675node...",
  "body": "Paciente estable, sin incidencias en la última hora.",
  "recorded_at": "2026-11-24T14:30:00Z"
}
```

- `patient_id` obligatorio; debe coincidir con la sesión.
- `node_id` opcional; si la sesión tiene nodo, debe coincidir si se envía.
- `body` obligatorio (1–20000 caracteres).
- `recorded_at` opcional (UTC); por defecto, ahora.

Respuesta **201**: objeto `SessionTextNoteOut` (`id`, `session_id`, `body`, `author_id`, `recorded_at`, …).

Permisos: **staff** (clinician/root).

La sesión puede estar **activa o cerrada** (no hace falta que siga activa para anotar).

### Listar notas de una sesión

```http
GET /sessions/{session_id}/text-notes?skip=0&limit=100
```

Respuesta: array de notas, más recientes primero.

Permisos: cualquier usuario autenticado con acceso a la API.

### Detalle

```http
GET /sessions/{session_id}/text-notes/{note_id}
```

### Editar texto

```http
PATCH /sessions/{session_id}/text-notes/{note_id}
Content-Type: application/json
```

```json
{
  "body": "Texto corregido."
}
```

Permisos: **staff**.

### Resumen de sesión

`GET /sessions/{session_id}/overview` incluye el campo `text_notes` (conteo).

## 2. Nota de audio (MinIO + MongoDB)

Flujo presigned: metadatos en API, binario directo a MinIO.

### Paso A — Pedir subida

```http
POST /audio
Content-Type: application/json
```

```json
{
  "session_id": "675sess...",
  "patient_id": "675abc...",
  "node_id": "675node...",
  "kind": "voice_note",
  "start_ts": "2026-11-24T14:30:00Z",
  "end_ts": "2026-11-24T14:30:45Z",
  "duration_seconds": 45.0,
  "format": "wav",
  "file_extension": "wav"
}
```

- `kind`: `"voice_note"` (nota de voz) o `"ambient"` (audio ambiente).
- Sesión debe estar **activa** para ingestar (igual que vitales/vídeo).

Respuesta **201**:

```json
{
  "id": "...",
  "bucket": "nilo-data",
  "object_key": "...",
  "upload_url": "https://...",
  "expires_in": 3600
}
```

### Paso B — Subir fichero

```http
PUT {upload_url}
Content-Type: audio/wav
```

Cuerpo: bytes del audio.

### Paso C — Confirmar

```http
POST /audio/{audio_id}/confirm
```

Sin body. Marca el clip como subido.

### Paso D — Transcripción (opcional, texto derivado del audio)

```http
PATCH /audio/{audio_id}/transcription
Content-Type: application/json
```

```json
{
  "transcription": "Texto transcrito de la nota de voz.",
  "transcription_status": "done"
}
```

Puede hacerlo el front tras STT o un worker.

### Consultas

```http
GET /audio?patient_id=...&session_id=...
GET /audio/{audio_id}
GET /audio/{audio_id}/download
```

`overview` de sesión: campo `audio_clips`.

---

## Comparación rápida

| | Nota texto | Nota audio |
|--|------------|------------|
| Ruta principal | `POST .../sessions/{id}/text-notes` | `POST /audio` + PUT + confirm |
| Almacenamiento | MongoDB | MinIO + metadatos MongoDB |
| Sesión activa | No obligatorio | Sí (ingesta) |
| Rol crear | staff | staff |

---

## Ejemplo fetch (texto)

```javascript
const BASE = "https://nilomed.eu/api/v1";

const res = await fetch(`${BASE}/sessions/${sessionId}/text-notes`, {
  method: "POST",
  headers: {
    Authorization: `Bearer ${accessToken}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({
    patient_id: patientId,
    body: "Nota clínica…",
  }),
});
```

## Ejemplo login + audio (resumen)

```javascript
const form = new URLSearchParams();
form.set("username", email);
form.set("password", password);
const login = await fetch(`${BASE}/auth/login`, {
  method: "POST",
  headers: { "Content-Type": "application/x-www-form-urlencoded" },
  body: form,
});
const { access_token } = await login.json();
// luego POST /audio, PUT upload_url, POST /audio/{id}/confirm
```
