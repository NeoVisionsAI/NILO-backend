# Transcripción de notas de voz (Whisper local)

Motor: **[faster-whisper](https://github.com/SYSTRAN/faster-whisper)** (modelo Whisper en CPU/GPU). Imagen Docker: **ffmpeg** para webm/ogg del navegador.

## Config (`config.yaml` / env)

| Variable | Default | Descripción |
|----------|---------|-------------|
| `TRANSCRIPTION_ENABLED` | `true` | Apagar en VMs sin CPU/RAM |
| `WHISPER_MODEL` | `small` | `tiny`, `base`, `small`, `medium`… |
| `WHISPER_LANGUAGE` | `es` | Código ISO; `null`/vacío = autodetect |
| `WHISPER_DEVICE` | `cpu` | `cuda` si hay GPU |
| `WHISPER_COMPUTE_TYPE` | `int8` | CPU recomendado |
| `AUTO_TRANSCRIBE_VOICE_NOTES` | `false` | Tras `POST /audio/upload` (background) |
| `TRANSCRIPTION_MAX_AUDIO_SECONDS` | `600` | Tope por clip |
| `WHISPER_WARMUP_ON_STARTUP` | `true` | Carga modelo al arrancar Uvicorn |

## Arranque y deploy

Con `WHISPER_WARMUP_ON_STARTUP=true` (default), al iniciar la API se **descarga** (si falta) y **carga** el modelo antes de servir tráfico útil: `/health` devuelve `ready: false` hasta terminar.

- **`./deploy.sh`** en la VM espera hasta **6 min** a `GET /health` con `ready: true` (incluye Whisper).
- Docker compose monta volumen `whisper_model_cache` → no re-descarga en cada redeploy.
- `healthcheck` `start_period: 300s` en `deploy/vm-ghcr/compose.yaml`.

Primera vez en un host vacío puede tardar varios minutos (descarga ~500 MiB para `small`).

## API

### Fichero suelto → texto

```http
POST /api/v1/audio/transcribe
Authorization: Bearer …
Content-Type: multipart/form-data
  file: <audio>
  language: es   (opcional)
```

→ `200` `{ "text": "…", "language": "es" }`

### Nota ya guardada en MinIO

```http
POST /api/v1/audio/{audio_id}/transcribe
Authorization: Bearer …
Content-Type: application/x-www-form-urlencoded   (body vacío OK)
```

Query / form: `force=false`, `language` opcional.

Actualiza `AudioRecording.transcription` y `transcription_status` (`done` / `failed`).

### Manual / externo

`PATCH /api/v1/audio/{audio_id}/transcription` (sin cambios).

## Modelo Mongo

`transcription`, `transcription_status`: `none` | `pending` | `done` | `failed`.

Notas de voz: `pending` al subir; `done` tras `/transcribe` o auto.

## Frontend sugerido

Tras grabar nota: `POST /audio/upload` → `POST /audio/{id}/transcribe` (spinner; puede tardar 10–60 s en CPU) → mostrar `transcription` en lista.

O activar `AUTO_TRANSCRIBE_VOICE_NOTES=true` y hacer polling de `GET /audio/{id}` hasta `transcription_status=done`.
