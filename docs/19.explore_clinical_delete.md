# DELETE recursos clínicos (Explorar sesión)

Contrato alineado con `NILO-frontend/docs/18.explore_clinical_delete.md`.

## Resumen

| Recurso | DELETE | MinIO |
|---------|--------|-------|
| Landmarks | `DELETE /landmarks/{id}` | `object_key` |
| Audio | `DELETE /audio/{id}` | `object_key` |
| Nota texto | `DELETE /sessions/{session_id}/text-notes/{note_id}` | — |
| Dolor | `DELETE /pain-events/{id}` | `video_object_key`, `landmarks_object_key` |
| Vídeo | `DELETE /sessions/video-segments/{segment_id}` | `object_key` |
| Fisiológico | `DELETE /physiological/{id}` | — |

- **204** sin cuerpo.
- **`require_staff`** en todos.
- MinIO: `minio_client.delete_object` idempotente (objeto ausente → log + sigue; borra Mongo).

Implementación: `app/services/clinical_delete.py`.
