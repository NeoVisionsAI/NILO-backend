# nginx: límite de cuerpo para subidas a la API (`413`)

Síntoma: `POST https://nilomed.eu/api/v1/landmarks/upload` → **413 Request Entity Too Large** con JSON MediaPipe real (cientos de puntos × muchos frames), mientras payloads pequeños funcionan.

La API acepta hasta **`MAX_PROXY_UPLOAD_BYTES`** (por defecto **64 MiB** tras descomprimir gzip). Si **nginx** corta antes (típico **1m**), la petición nunca llega a FastAPI.

## nilomed.eu — bloque API

Dentro del `server` que sirve el front y proxifica la API:

```nginx
location ^~ /api/ {
    client_max_body_size 64m;
    proxy_read_timeout 300s;
    proxy_send_timeout 300s;
    proxy_pass http://nilobackend.com:8001;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Forwarded-Proto $scheme;
    proxy_set_header Authorization $http_authorization;
}
```

Recargar nginx (`sudo nginx -t && sudo systemctl reload nginx`).

## Verificación

```bash
# Generar ~2 MiB JSON de prueba
python3 - <<'PY'
import json, pathlib
payload = {"schema": "nilo-mediapipe-face-capture-v1", "frames": [{"t": i, "p": [0.0]*478*3} for i in range(800)]}
pathlib.Path("/tmp/landmarks_big.json").write_text(json.dumps(payload))
print(len(open("/tmp/landmarks_big.json","rb").read()), "bytes")
PY

curl -sS -o /dev/null -w "%{http_code}\n" \
  -X POST "https://nilomed.eu/api/v1/landmarks/upload" \
  -H "Authorization: Bearer $TOKEN" \
  -F "session_id=..." \
  -F "patient_id=..." \
  -F "start_ts=2026-11-24T12:00:00Z" \
  -F "source=mediapipe" \
  -F "file=@/tmp/landmarks_big.json;type=application/json"
```

Esperado: **201** (no 413).

## Frontend: comprimir (recomendado)

Para episodios **1–2 min**, enviar el JSON con **gzip**:

- `CompressionStream('gzip')` en el navegador.
- Parte `file`: `landmarks.json.gz`, `type: application/gzip`.
- El backend descomprime y guarda **JSON** en MinIO.

Reduce ancho de banda y evita rozar el límite de nginx sin subir a cientos de MiB.

Ver ampliación en `docs/13.mensaje_agente_frontend_minio_upload.md` (sección landmarks gzip).
